# MVP для курсовой работы "City Problem Map"

## 1. **Цель MVP**
MVP представляет собой минимально работоспособную версию системы для отображения и добавления проблем на карте города. Система состоит из двух отдельных приложений:

- **frontend** — интерфейс обычного пользователя  
- **frontend-admin** — административная панель  
- **ui-lib** — библиотека общих UI-компонентов  

Все данные хранятся в LocalStorage.

---

## 2. **Роли**

### Обычный пользователь (frontend):
- добавляет события на карту;
- видит список событий;
- фильтрует события по типу;
- просматривает простую статистику.

### Администратор (frontend-admin):
- видит все события;
- меняет статус события: *новое → в работе → выполнено*;
- удаляет события;
- просматривает расширенную статистику.

Админ-панель запускается как отдельное приложение, сделано без авторизации.

---

## 3. **Основной функционал MVP**

### В приложении frontend:
- отображение карты с маркерами;
- добавление события (выбор точки, заголовок, тип, описание);
- сохранение данных в LocalStorage;
- фильтрация по типам;
- просмотр количества событий.

### В приложении frontend-admin:
- список всех событий;
- изменение статусов;
- удаление событий;
- статистика по типам и статусам.

---

## 4. **Use Case — основной сценарий**

### **Добавление события (пользователь)**  
1. Пользователь открывает страницу `/events`.  
2. Нажимает кнопку «Добавить событие».  
3. Выбирает точку на карте.  
4. Заполняет форму.  
5. Сохраняет событие, оно появляется на карте и сохраняется в LocalStorage.

### **Изменение статуса (администратор)**  
1. Администратор открывает `/admin/events`.  
2. Выбирает событие.  
3. Меняет статус на «в работе» или «выполнено».  
4. Изменение сохраняется в LocalStorage.
