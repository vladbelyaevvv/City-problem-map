# City-problem-map

Чтобы проверить нужно сделать: 
1. Установить зависимости `npm install`
2. Перейти в папку frontend `cd frontend`
3. Запустить `npm run lint`
4. Запустить `npm run test` и `npm run test:coverage`
5. Запустить `npm run dev` и посмотреть сайт
6. Перейти в папку frontend-admin `cd ../frontend-admin`
7. Запустить `npm run lint`
8. Запустить `npm run test` и `npm run test:coverage`
9. Запустить `npm run dev` и посмотреть сайт
10. Перейти в папку ui-lib `cd ../ui-lib`
11. Запустить `npm run lint`
12. Запустить `npm run test` и `npm run test:coverage`
13. Запустить `npm run dev` и посмотреть сайт
